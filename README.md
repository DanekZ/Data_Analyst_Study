## 🚀 Cara Menggunakan
 
1. Clone repositori ini:
```bash
   git clone https://github.com/DanekZ/Data_Analyst_Study.git
   cd Data_Analyst_Study
```
 
2. Install dependensi yang dibutuhkan:
```bash
   pip install numpy pandas matplotlib seaborn requests jupyter
```
 
3. Jalankan Jupyter Notebook:
```bash
   jupyter notebook
```
 
4. Buka folder sesi yang ingin dipelajari dan jalankan notebook-nya.
